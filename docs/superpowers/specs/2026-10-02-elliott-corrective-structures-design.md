# 엘리어트 조정·다이아고날 구조 작도 설계 (2026-10-02)

## 배경

siglens 엘리어트 스킬(`skills/strategies/elliott-wave.md`)은 지그재그·플랫·삼각형(A-B-C-D-E)·복합 조정(W-X-Y, W-X-Y-X-Z)·다이아고날을 설명하고, 모델은 본문에 그 구조를 쓴다. 그러나 core 작도(`domain/overlays/elliottCandidates.ts`)는 충격파 1~5와 **완성된 충격파 뒤의** A-B-C만 센다. 모델이 "삼각형 조정"이라고 써도 차트엔 그릴 후보가 없다.

## 목표 / 비목표

- 목표: 아래 4개 구조를 로직이 계산해 `kind: 'elliott'` 후보로 제시하고, 모델이 고르면 그린다.
  1. 삼각형 A-B-C-D-E (수렴형, 드물게 확산형)
  2. 복합 조정 W-X-Y / W-X-Y-X-Z
  3. 다이아고날 (선행·종결)
  4. A-B-C 유형 판정 (지그재그 / 플랫: 정규·확장·러닝)
- 조정파는 **단독**(앞에 충격파 없이)으로도 세고, 오른쪽 끝에서 **진행 중**인 것도 센다(예: A-B-C-D 후 "E 진행 중").
- **출시 게이트:** 가짜 봉 데이터 검증을 통과한 구조만 켠다(아래 §검증). 미통과 구조는 코드에 두되 비활성(`ELLIOTT_ENABLED_STRUCTURES`에서 제외)으로 출시하고 수치를 보고한다.
- 비목표: 하위 차수(sub-wave) 세분화 검증(3-3-3-3-3 내부 구조), 프롬프트 템플릿 버전 변경을 수반하는 지시문 개편, siglens UI 신규 컴포넌트.

## 구조별 판정 규칙

공통: 피벗은 기존 `extractPivots(bars.slice(offset), atr, { includeProvisional: true })`(1.5 ATR zigzag)를 쓴다. 인접 피벗은 고/저가 번갈아야 하고 `EW_MIN_WAVE_BARS` 이상 떨어져야 한다(`alternates`). 구조 전체 길이는 `EW_MIN_IMPULSE_SPAN_BARS` 이상. 후보 id의 방향(`up`/`down`)은 구조의 첫 다리 방향으로 정한다(라벨을 고점 위/저점 아래에 놓는 데만 쓰인다).

### 1. 삼각형 A-B-C-D-E

- 피벗 6개 p0..p5(p0=시작, p1..p5=A..E 끝). 진행 중은 p0..p4(5개, E 진행 중)까지 허용.
- 수렴형: 고점열은 낮아지고 저점열은 높아진다(첫 다리가 하락이면 p0,p2,p4가 고점: p2<p0, p4<p2; p1,p3,p5 저점: p3>p1, p5>p3). 각 다리 길이가 앞 다리보다 짧다(C<A, D<B, E<C) — 허용 오차 `EW_TRI_LEG_TOLERANCE`.
- 확산형: 부등호 반대(고점 상승·저점 하락, 각 다리 길어짐). 점수 감점(드묾).
- E는 A-C 경계선을 크게 넘지 않는다(오버슈트 허용 `EW_TRI_E_OVERSHOOT`, ATR 단위).
- 작도: 다리 5개(실선), 경계선 2개(A 끝-C 끝을 잇는 선과 B 끝-D 끝을 잇는 선, 점선, 마지막 피벗 시각까지), 라벨 A..E.
- 점수: 수렴 정도(두 경계선 기울기 부호 반대), 다리 길이 단조 감소, 소요 기간 균형, 최근성.

### 2. 복합 조정 W-X-Y (/ W-X-Y-X-Z)

- 단순 조정 W, Y(, Z)는 각각 3다리(A-B-C) 이상으로 볼 수 있으나, 피벗 해상도상 **피벗 4개 = 한 단순 조정**(시작-A-B-C)로 근사한다. W-X-Y = 시작, W의 A, W의 B, W 끝(=W), X 끝, Y의 A, Y의 B, Y 끝 → 피벗 8개. W-X-Y-X-Z = 12개. 진행 중: Y(또는 Z)의 마지막 다리가 진행 중이면 1개 적은 피벗까지 허용.
- 규칙: W·Y는 같은 방향의 순 이동. X는 W의 반대 방향이며 W 순 이동의 100% 미만 되돌림(`EW_COMBO_X_MAX_RETRACE`). Y의 순 이동 크기는 W의 `EW_COMBO_Y_TO_W_MIN`~`MAX` 배.
- 라벨은 구조 경계에만: W, X, Y(, X, Z). 내부 a-b-c 라벨은 그리지 않는다(라벨 과밀 방지). 다리는 경계 피벗을 잇는 선으로 단순화한다.
- 점수: W/Y 크기 비 대칭, X 되돌림 깊이(38.2~78.6% 선호), 횡보성(전체 순 이동/총 이동 경로 작을수록), 최근성.

### 3. 다이아고날 (선행/종결)

- 기존 충격파 열거(`enumerate`)에서 **규칙 3(4파가 1파 영역 침범 금지)만** 위반한 카운트를 다이아고날 후보로 재평가한다. 규칙 1·2는 그대로 요구.
- 추가 조건: 1-3-5 고점선과 2-4 저점선(하락이면 반대)이 수렴(쐐기)하고, 수렴형에서 파동 크기 w1>w3>w5(허용 오차). 확산형은 감점.
- 선행/종결 구분: 카운트 시작 전에 같은 방향 추세가 있었으면 종결(ending), 반대 방향이거나 없으면 선행(leading) — 판정 근거가 약하면 promptLine에 "leading or ending"으로 둔다.
- 작도: 1~5 라벨 + 두 경계선(점선). id에 `:diag` 접미사.

### 4. A-B-C 유형 판정 (지그재그 / 플랫)

- 기존 `abcAfter`가 붙이는 A-B-C와, 새로 허용하는 **단독 A-B-C**(피벗 4개, 진행 중 3개) 모두에 적용.
- 지그재그: B가 A의 61.8% 이하 되돌림이고 C가 A 끝을 넘어선다.
- 플랫: B가 A의 `EW_FLAT_B_MIN`(≈90%) 이상 되돌림. 정규(B≈A 시작, C≈A 끝), 확장(B가 A 시작을 넘고 C가 A 끝을 넘음), 러닝(B가 A 시작을 넘고 C가 A 끝에 못 미침).
- 결과는 promptLine 문구(`zigzag` / `regular flat` / `expanded flat` / `running flat`)와 C 라벨 옆 설명이 아니라 **promptLine에만** 싣는다(라벨 텍스트는 A/B/C 유지 — 화면 과밀 방지). 단독 A-B-C의 점수는 충격파 뒤 A-B-C보다 낮게 시작한다.

## 후보 제시·선택

- 구조 종류별(`impulse`, `diagonal`, `triangle`, `combination`, `abc`)로 점수 상위를 모은 뒤 **종류마다 최고 1개씩 우선**, 남는 자리는 전체 점수 순으로 채운다. 전체 상한 `ELLIOTT_CANDIDATE_LIMIT`를 3 → 5로 올린다(프롬프트 길이 영향은 §영향에서 측정).
- id 형식: 기존 `ew:{dir}:{startTime}:{n}`(+`:abc`) 유지, 새 구조는 `ew:{dir}:{startTime}:{tri|combo|combo3|diag|abc}` 계열로 구분 — 기존 캐시·테스트와 충돌 없음.
- promptLine: 구조 이름과 상태(`triangle (contracting); E in progress; A 123.4 (2026-09-01), …; score 0.71`). 모델은 기존처럼 id를 `strategyResults[].candidateIds`에 적는다(엘리어트 카드, 최대 2개 primary/alternate — 변경 없음).
- 프롬프트 지시문(템플릿)은 바꾸지 않는다. 후보 섹션의 줄만 늘어나므로 `PROMPT_TEMPLATE_VERSION` 범프 없음(기존 정책: 후보 섹션은 매 요청 바이트가 바뀜).

## 검증 (출시 게이트)

`src/__tests__/domain/overlays/elliottSynthetic/` 아래 결정적 생성기(시드 고정 PRNG)와 측정 스크립트를 둔다.

- 생성기: 구조별 교과서 피벗 열(크기·기간 무작위 변주) → 피벗 사이를 직선 보간 + 가우시안 잡음(σ = k·ATR, k ∈ {0.1, 0.25}) → OHLC 봉. 앞뒤로 무작위 보행 구간을 붙여 구조가 차트 중간·오른쪽 끝(진행 중)에 오게 한다. 구조당 300표본.
- 대조군: 순수 무작위 보행(드리프트 0, 같은 길이) 1,000표본.
- 지표(구조별):
  - 정탐률: 해당 구조 후보가 상위 `ELLIOTT_CANDIDATE_LIMIT` 안에 있고 라벨 피벗이 실제 피벗 ±`EW_MIN_WAVE_BARS`봉 이내.
  - 오탐률: 대조군에서 그 구조 후보가 나온 비율.
  - 다른 구조로 잘못 분류된 비율(혼동 행렬).
- 게이트: 정탐 ≥ 80%(잡음 0.1) / ≥ 60%(잡음 0.25), 대조군 오탐 ≤ 5%, 혼동 ≤ 10%. 통과 구조만 `ELLIOTT_ENABLED_STRUCTURES`에 넣는다.
- 회귀: 기존 충격파·A-B-C 테스트 전부 유지. 생성기 기반 게이트는 vitest 테스트로 고정(표본 수를 줄인 빠른 버전) + 전체 측정은 `scripts/`의 수동 실행 스크립트.
- 실데이터: 운영 분석 재생(오버레이 재생 하네스, siglens 메모리 참조)으로 새 구조 후보 빈도와, 기존 충격파 후보가 상위에서 밀려나는 비율을 측정해 보고.

## 영향

- 출력 값 변경(새 후보·후보 수 증가), 공개 API 시그니처 불변. `ELLIOTT_CANDIDATE_LIMIT` 등 상수는 `@internal`.
- 프롬프트 바이트 증가(후보 줄 최대 +2) — 측정해 PUBLIC_API 변경 이력에 기록. 캐시 키 불변.
- siglens: 라벨·선은 core가 만들므로 코드 변경 없음이 기본. 경계선(점선)이 기존 엘리어트 색으로 그려지는지만 확인하고, 필요하면 siglens에서 선 역할(role)별 스타일만 조정.

### 공통

- **짧은 다리 병합(`mergeShortLegs`).** 일봉에서 넓은 봉 하나가 고점·저점 피벗을 같은(또는 이웃) 봉에 함께 찍는 일이 흔하다(실데이터 8종목: 피벗 21–85개 중 9–55개). `alternates`가 이런 0~1봉 다리를 거부하면 그 위를 지나는 카운트가 전부 깨지므로, 모든 구조가 EW_MIN_WAVE_BARS 미만 다리를 병합한 피벗을 쓴다(같은 종류가 이어지면 더 극단값을 남김).
- **시간 균형(`EW_TIME_BALANCE_MIN = 1/3`).** 삼각형·다이아고날은 가장 짧은 다리 기간 ≥ 가장 긴 다리의 1/3(진행 중 마지막 다리는 제외). 무작위 보행 오탐에 대한 가장 강한 단일 필터. 단, 생성기의 삼각형·다이아고날 다리 기간이 고르게 뽑히므로 다리 시간이 크게 들쭉날쭉한 실제 패턴의 정탐률은 이보다 낮을 수 있다.
- **확장형 삼각형·확장형 다이아고날은 세지 않는다.** 보행 오탐만 2.5%/3.3% 늘리고 정탐 이득은 측정되지 않았다(드묾).
- **구조당 상한 `ELLIOTT_PER_STRUCTURE_LIMIT = 3`**(전체 5). 종류별 최고 1개 우선 후 점수순.
- **진행 중 문구.** 피벗 목록은 항상 오른쪽 끝의 진행 중 극값을 포함하므로, 5피벗 삼각형은 "E 진행 중"이 아니라 `D forming, E next`, 6피벗 오른쪽 끝은 `E in progress`. 단독 A–B–C는 3피벗(B 진행 중)을 세지 않는다(구조 정보가 없음).

### 구조별

- **충격파(추가 요구 A).** v2.5.0의 원시 피벗 카운트는 게이트 기준선 정탐 16.3%/2.7%(넓은 봉 피벗 때문). 병합 피벗만 쓰면 정탐 ~100%·보행 오탐 ~79%라 필터 추가: 3파 ≥ 1파, 2파 되돌림 23.6–88.6%, 4파 14.6–61.8%(진행 중 4파는 상한만), 완성 파동마다 ≥ `EW_MIN_WAVE_ATR`(2.5 ATR; 생성기 최소 다리 ≈ 2.3–3 ATR이므로 정탐 수치는 그 크기 이상의 파동을 전제), 완성 5파는 3파 끝을 넘음(절단 제외), 3파 진행 중(4피벗) 카운트 폐기(어떤 상승-하락-상승에도 맞음). 실데이터: 기존 충격파 후보 460개 중 같은 id로 남은 것 3개 — 충격파 후보는 사실상 새로 계산된다(재생 중 충격파 제시 410 → 138회).
- **A–B–C 유형.** 지그재그 B 상한 61.8% → **78.6%**(교과서 38.2–78.6% 대역 상단). 피벗이 꼬리 극값에 찍혀 50–60% B가 62–69%로 측정됐다. 진행 중 C가 이미 A 끝을 넘었으면 `expanded flat`(C는 늘어날 뿐), 못 미쳤으면 `expanded or running flat`. 확장 플랫 유형 정확도 53–62% → 100%/97.1%(진행 중 `expanded or running`을 정답으로 셈 — 하네스가 그 문구 안의 "running flat"을 잘못 읽던 버그도 수정). 충격파 뒤 A–B–C 유형은 항상 표시(단독 A–B–C 게이트와 분리).
- **삼각형.** 다리마다 직전 다리의 ≥ 50% 되돌림(`EW_TRI_LEG_RATIO_MIN`, 횡보성), A 시작이 B–D선 밖(±0.5 ATR), 완성 E는 D에서 A–C선까지의 ≥ 60% 도달(`EW_TRI_E_MIN_REACH`) + 오버슈트 ≤ 1 ATR.
- **다이아고날.** 규칙 3만 깨진 0–5 카운트 중 4파가 1파를 실제로 침범하고(규칙 2 부분형 실패로 들어온 것 제외), 0이 2–4선에서, 완성 5파가 1–3선에서 1파의 20% 이내. 4파 진행 중 카운트는 세지 않음(오탐 +1.3%p, 정탐 측정 불가).
- **복합 조정.** 진입 추세 요구(`priorTrend`: 시작점 이전 W 기간의 봉에서 시작점이 극값이고 W 첫 다리의 ≥ 1배 이동, 피벗 창 밖 추세도 봉으로 확인) + 모든 다리 ≥ 2.5 ATR로 보행 오탐 44.1% → 1.3–1.8%. 점수의 "횡보성" 항목은 진입 추세 크기 항목으로 교체(횡보성은 본래 날카로운 이중 지그재그를 깎아 겹친 다이아고날보다 아래로 보냈다). 혼동 9.3–14.3%로 시드 3개 중 2개에서 10% 초과 → **끔**. 남은 혼동은 대부분 W–X 앞부분이 다이아고날로도 읽히는 실제 엘리어트 모호성이다.

### 프롬프트 줄 (추가 요구 E)

로직이 계산할 수 있는 값은 후보 줄에 싣는다(공용 `elliottPromptLine`, 가격은 `priceDp`, 비율은 소수 1자리 %):
- 충격파: `invalidation` — 4파 진행 중 → 1파 끝(규칙 3), 5파 진행 중 → 4파 끝, 완성(A–B–C 유무 무관) → 5파 끝(그 너머 새 극값이면 5파가 아직 연장 중이라 "충격파 완성"이 무너진다; 완성 뒤 4파 끝 이탈은 조정 확인일 뿐). 붙은 A–B–C의 B는 5파 끝을 넘지 못하므로(`abcAfter`) 같은 값이 A–B–C의 무효화(지그재그의 A 시작)이기도 하다. + `W2 …% of W1, W3 …% of W1, W4 …% of W3, W5 …% of W1`(완성 파동만) + 붙은 A–B–C의 `C target`.
- 다이아고날: 5파 진행 중 `invalidation <4파 끝>; wave 5 cap <4파 끝 ± 3파 길이>`, 완성 `invalidation <cap>`(5파가 3파보다 길어지면 수렴 다이아고날이 깨짐) + 파동 비율.
- 삼각형: `invalidation`(D 진행 중 → B 끝, E 진행 중·완성 → C 끝; 평평한 변 허용오차로 이미 넘었으면 그 다리 끝), 완성 시 `thrust target`(A 끝과 그 시점 B–D선 사이 폭을 E에서 A 반대 방향으로).
- 단독 A–B–C: `C target 100% …, 161.8% …`(B 기준 A 길이), 지그재그만 `invalidation <A 시작>`(플랫은 B가 A 시작을 넘을 수 있어 없음).
- 복합 조정: `W …, X … (…% of W), Y …`.
